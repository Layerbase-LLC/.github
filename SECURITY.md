# Security Policy

We take the security of Layerbase and its open source projects seriously.

## Reporting a vulnerability

- **Email**: [bob@layerbase.com](mailto:bob@layerbase.com) — include steps to reproduce and the affected project/version.
- Please do not open a public issue for security reports.

You'll get an acknowledgment as quickly as possible, typically within 48 hours.

## More

See [layerbase.com/security](https://layerbase.com/security) for details on how Layerbase Cloud handles encryption, isolation, and data protection.
